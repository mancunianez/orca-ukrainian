# Orca Ukrainian language pack

Перекладає інтерфейс Orca українською. Ключі дзеркалять англійський каталог Orca
(`src/renderer/src/i18n/locales/en.json`); переклад — у `locales/uk.json`.

- Покриття: 100% рядків, які Orca дозволяє перекладати (security-копірайт Orca
  тримає англійською за замовчуванням).
- Форми множини: CLDR `one/few/many/other` для української.
- Content-only плагін (`execution: data`): нічого не виконується, схвалення не потрібне.

## Оновлення при зміні англійського каталогу

1. Додайте нові ключі до `locales/uk.json` (структура та плейсхолдери `{{…}}` мають
   збігатися з `en.json`).
2. `ORCA plugin validate .` — строга перевірка каталогу.
3. Покриття має лишатися ≥ 80%, інакше мову не можна обрати у налаштуваннях.
